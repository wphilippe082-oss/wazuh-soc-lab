# Preuves et captures d’écran

Ajouter des captures expurgées montrant :

1. L’état des conteneurs Wazuh et de l’API.
2. L’inventaire des agents Windows et Ubuntu.
3. L’événement Windows Security 4624 dans Wazuh.
4. La télémétrie Sysmon dans Wazuh.
5. Les événements SSH, UFW et Fail2ban d’Ubuntu.
6. Le résumé du scan Nessus.
7. Les événements Suricata dans Wazuh, uniquement après validation de bout en bout.

Avant de publier les captures :
- Masquer les mots de passe, jetons, hashes, clés API et clés d’enrôlement.
- Supprimer les adresses e-mail personnelles et onglets de navigateur sans rapport.
- Vérifier les noms d’hôtes, noms d’utilisateurs, adresses IP publiques et détails du réseau interne.
- Ne jamais téléverser les fichiers bruts `eve.json`, `alerts.json`, `archives.json` ou des journaux complets de terminaux.
