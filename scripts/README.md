# Scripts

Placer ici uniquement des scripts auxiliaires vérifiés et dépourvus de secrets.

Pour chaque script, documenter :
- Son objectif et le résultat attendu
- Le système et la version pris en charge
- Les privilèges nécessaires
- Les entrées et paramètres configurables
- Les contrôles de sécurité et possibilités de retour arrière

Ne jamais stocker de mots de passe d’enrôlement, clés API, clés privées ou jetons dans les scripts.
